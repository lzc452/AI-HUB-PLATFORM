## 1. 整体布局架构

### 1.1 布局结构

```
┌──────────────────────────────────────────────────────────┐
│  HEADER（固定顶部，高度 56px）                              │
│  ┌──────┬──────────────────────────┬──────────────────┐  │
│  │ Logo │    搜索框（应用市场页）    │ 消息通知 / 用户信息 │  │
│  └──────┴──────────────────────────┴──────────────────┘  │
├────────┬─────────────────────────────────────────────────┤
│ SIDEBAR│            CONTENT AREA                         │
│ 菜单1  │  ┌───────────────────────────────────────────┐  │
│ 菜单2  │  │  面包屑导航                                  │  │
│ 菜单3  │  │  ────────────────────────────────────────  │  │
│ 菜单4  │  │                                            │  │
│ 菜单5  │  │  页面内容区域                                │  │
│        │  │  (超屏幕高度时纵向滚动)                       │  │
│        │  │                                            │  │
│        │  │                                            │  │
│        │  └───────────────────────────────────────────┘  │
│────────│                                                 │
│ 平台   │                                                 │
│ 公告   │                                                 │
└────────┴─────────────────────────────────────────────────┘
```

### 1.2 布局规则

| 区域 | 宽度 | 高度 | 滚动 |
|------|------|------|------|
| Header | 100% | 固定 56px | 无 |
| Sidebar | 默认 220px，收起 64px | 撑满视口减 Header 高度 | 菜单项过多时内部滚动；底部公告固定 |
| Content | 剩余宽度 | 撑满视口减 Header 高度 | 超出时纵向滚动 |

### 1.3 响应式断点

| 断点 | 宽度 | Sidebar 行为 |
|------|------|-------------|
| 大屏 | ≥ 1200px | 默认展开，可手动收起 |
| 中屏 | 768–1199px | 默认收起，点击展开为浮层 |
| 小屏 | < 768px | 默认收起，点击展开为浮层 |

### 1.4 全局样式规范

- **主操作色**: `#1677ff`（Ant Design 默认蓝）
- **背景色**: 页面 `#f5f5f5`，卡片 `#ffffff`
- **文字色**: 主要 `#1f1f1f`，次要 `#595959`，禁用 `#bfbfbf`
- **边框色**: `#d9d9d9`
- **字体**: 系统默认中文字体（不依赖公网字体）
- **动效**: 150–300ms，优先透明度/位移/颜色变化，支持 `prefers-reduced-motion`
- **图标**: `@ant-design/icons` 统一使用
- **语言**: 简体中文

## 2. 全局交互规范

### 2.1 加载状态

| 场景 | 表现 |
|------|------|
| 页面首次加载 | 骨架屏（Skeleton），模拟内容布局 |
| 局部数据刷新 | Spin 居中或覆盖目标区域 |
| 提交/操作处理中 | 按钮 loading + disabled |
| 文件处理中 | 进度条 + 状态文字 |

### 2.2 空状态

| 场景 | 表现 |
|------|------|
| 无数据列表 | Empty 组件 + 引导文案 + 可选操作按钮 |
| 搜索无结果 | Empty + "未找到匹配结果，请调整搜索条件" |
| 无权限 | Result 组件（403）+ "您没有访问此页面的权限" |

### 2.3 错误状态

| 场景 | 表现 |
|------|------|
| 网络/服务错误 | Alert type="error" + 错误描述 + 重试按钮 |
| 表单校验错误 | 字段下方红色提示 + message 顶部通知 |
| 并发冲突 | Modal 提示 "数据已被他人修改，请刷新后重试" |

### 2.4 操作反馈

| 类型 | 组件 | 持续 |
|------|------|------|
| 操作成功 | message.success | 3s 自动消失 |
| 操作失败 | message.error | 5s 自动消失，可手动关闭 |
| 重要确认 | Modal.confirm | 用户确认后关闭 |
| 长时间处理 | notification 进度 | 完成后自动更新 |

### 2.5 可访问性

- 跳过导航链接（skip-link），跳至 `#main-content`
- 语义化标题层级（h1-h6）
- 键盘导航：Tab 切换焦点，Enter/Space 激活，焦点可见样式
- 非颜色状态表达：图标 + 文字 + 颜色三重表达
- `aria-label` 标注交互区域

## 3. 头部区域

### 3.1 布局

```
┌──────────────────────────────────────────────────────────────┐
│  [Logo + 平台名称]          [🔍 搜索框]      [🔔] [👤 用户名 ▼] │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 各部分说明

#### 3.2.1 左侧：Logo + 平台名称

- Logo 图标 + 「AI 应用市场」文字
- 点击跳转至首页（应用市场）
- 高度与 Header 对齐，垂直居中

#### 3.2.2 居中：全局搜索框（仅应用市场页面显示）

- **页面范围**: 仅在「应用市场」页面显示
- **其他页面**: 中部区域留空
- **样式**: Ant Design `Input.Search`，宽度 400px，圆角
- **占位符**: "搜索应用名称、标签、场景…"
- **交互**:
  - 输入文字后回车或点击搜索图标触发搜索
  - 输入框右侧有清除按钮
  - 支持拼音首字母匹配（后端实现）
  - 搜索触发后跳转/刷新应用市场搜索结果

#### 3.2.3 右侧：消息通知 + 用户信息

**消息通知（Bell 图标）**:
- `BellOutlined` 图标按钮，带 Badge 显示未读数
- 点击弹出下拉面板（Popover），显示最近 5 条未读通知
- 面板底部「查看全部通知」链接 → 跳转通知页面
- 空状态: "暂无新通知"

**用户信息（Dropdown）**:
- 显示当前用户姓名 + `DownOutlined`
- 点击弹出下拉菜单：
  - 「我的应用」→ `/applications`
  - 「创作者中心」→ 对应应用 `/creator/:id`
  - 「账号安全」→ 账号设置（后续版本）
  - ── 分隔线 ──
  - 「退出登录」→ 确认后执行登出

### 4.1 菜单结构

根据用户角色动态显示菜单项（前端根据角色控制显示，后端执行权限校验）：

```
┌─────────────────────┐

│ 💡  创新广场         │  ← 所有员工可见
│ 📋  应用管理         │  ← 应用管理员可见
│ ✅  审核工作台       │  ← 应用管理员可见
│ 📊  数据看板         │  ← 按角色可见不同看板
│ 🏢  组织管理         │  ← 组织管理员可见
│ 🔒  系统安全         │  ← 超级管理员可见
│ 🤖  AI 助手          │  ← 所有员工可见
│                     │
│                     │
│                     │
│ ─────────────────── │  ← 分隔线
│ 📢  平台公告         │  ← 固定底部
│ <小喇叭图标>        │
│ 系统将于本周五...   │
└─────────────────────┘
```

### 4.2 菜单项设计

| 属性 | 说明 |
|------|------|
| 图标 | 每个菜单项前有对应图标 |
| 高亮 | 当前激活菜单项：蓝色背景 (`#e6f4ff`) + 蓝色文字 (`#0958d9`) + 左侧蓝色指示条 |
| Hover | 未激活项悬停：浅灰背景 |
| 收起 | 收起时仅显示图标，鼠标悬停展开文字 tooltip |
| 展开/收起按钮 | Sidebar 顶部（logo 下方）或底部有折叠按钮 `<MenuFoldOutlined />` / `<MenuUnfoldOutlined />` |

### 4.3 菜单项与角色权限映射

| 菜单项 | 图标 | 路由 | 可见角色 |
|--------|------|------|---------|
| 应用市场 | `AppstoreOutlined` | `/marketplace` | 所有员工 |
| 创新广场 | `ExperimentOutlined` | `/innovation` | 所有员工 |
| 应用管理 | `AppstoreAddOutlined` | `/applications` | 应用管理员+ |
| 审核工作台 | `CheckCircleOutlined` | `/applications/:id/review` | 应用管理员+ |
| 数据看板 | `DashboardOutlined` | `/analytics` | 按角色 |
| 组织管理 | `TeamOutlined` | `/organization` | 组织管理员+ |
| 系统安全 | `SafetyCertificateOutlined` | `/security` | 超级管理员 |
| AI 助手 | `RobotOutlined` | `/assistant` | 所有员工 |

### 4.4 平台公告区

- 固定在 Sidebar 底部
- 小喇叭图标 `SoundOutlined`（橙色或蓝色） + 「平台公告」标题
- 显示最新一条公告摘要（单行截断）
- 点击弹出 Modal 或跳转查看完整公告
- 无公告时显示 "暂无公告"

### 4.5 Sidebar 收起/展开

- **展开状态（默认）**: 宽度 220px，显示图标 + 文字
- **收起状态**: 宽度 64px，仅显示图标居中排列
- **切换触发**:
  - 点击侧边栏底部折叠按钮
  - 快捷键（可选，后续版本）
- **过渡动画**: `width 0.2s ease`

**角色**: 所有已登录员工

### 5.1 页面布局

```
┌─────────────────────────────────────────────────────────┐
│  [ 推荐  | 最新  | 热门 ]  排序切换                       │
│                                                         │
│  [分类: 全部 ▼] [类型: 全部 ▼] [部门: 全部 ▼] [标签: 全部 ▼]│ = 筛选栏
│                                                         │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐               │
│  │ 应用卡片  │ │ 应用卡片  │ │ 应用卡片  │               │
│  └──────────┘ └──────────┘ └──────────┘               │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐               │
│  │ 应用卡片  │ │ 应用卡片  │ │ 应用卡片  │               │
│  └──────────┘ └──────────┘ └──────────┘               │

│  ──────────── 侧边栏（推荐位/热门标签）────────────────    │
└─────────────────────────────────────────────────────────┘
```

### 5.2 功能与交互

#### 5.2.1 排序切换

- 横向标签式切换：「推荐」「最新」「热门」
- 当前选中项高亮（蓝色下划线或背景）
- 对应 API 参数 `sort: "recommended" | "latest" | "popular"`

#### 5.2.2 筛选栏

| 筛选项 | 组件 | 选项来源 |
|--------|------|---------|
| 分类 | Select（单选） | 后端分类列表 |
| 应用类型 | Select（单选） | Web / 桌面端 / 移动端 / 小程序 |
| 部门 | Select（单选，可搜索） | 部门列表 |
| 标签 | Select（多选） | 热门标签 |
| 重置 | Button / Link | 清除所有筛选条件 |

- 筛选变更即时触发列表刷新
- 筛选栏始终可见，滚动时不隐藏

#### 5.2.3 应用卡片 (AppCard)

每个应用卡片展示：

```
┌─────────────────────────────┐
│  [图标]                     │
│                             │
│  应用名称                    │
│  一句话简介（2行截断）        │
│                             │
│  🏢 部门名称                 │
│  ⭐ 4.2 (128)  👍 256       │  ← 评分 + 点赞数
│                             │
│  [实验性] [已验证]          │  ← 信任标签
│  [Web] [小程序]             │  ← 交付渠道图标
└─────────────────────────────┘
```

- 点击卡片 → 跳转应用详情 `/marketplace/:applicationId`
- 卡片网格：3列（大屏）/ 2列（中屏）/ 1列（小屏）
- Hover 效果：轻微阴影提升 + 边框变色

#### 5.2.4 侧边栏（右侧）

- **管理员推荐位**: 展示 3-5 个推荐应用（小卡片或列表）
- **热门标签**: 标签云，点击后添加到筛选条件
- **最新上架**: 时间排序的 5 个最新应用
- **使用指南**: 4 个问题（找应用 / 使用与权限 / 申请发布 / 常见问题），点击条目弹出 Modal 展示对应引导文本（引导句 + 分步操作 + 提醒）

#### 5.2.5 状态处理

| 状态 | 表现 |
|------|------|
| 加载中 | 骨架屏：3×2 个 Skeleton 卡片 |
| 无结果 | Empty + "没有符合条件的已发布应用" |
| 错误 | Alert + "应用列表加载失败" + 重试按钮 |
| 全部加载 | 隐藏"加载更多"按钮，显示 "已展示全部 N 个应用" |

**角色**: 所有已登录员工（受众内）

### 6.1 页面布局

```

│  │          ⭐ 4.2 (128)  👍 256                        ││
│  │                                       [开始使用] 按钮 ││
│  └─────────────────────────────────────────────────────┘│
│                                                         │
│  [概述] [版本] [评价] [风险说明]                          │ = Tab 切换
│                                                         │
│  ── 当前 Tab 内容区域 ──                                 │
│                                                         │
│  ┌────────────────────┐ ┌──────────────────┐           │
│  │     截图区域        │ │  应用信息卡片     │           │

│  │                    │ │  维护人: 张三...  │           │
│  │                    │ │  标签: ...        │           │
│  │                    │ │  ──────           │           │
│  │                    │ │  操作手册 📥      │           │
│  │                    │ │  使用示例 📥      │           │
│  │                    │ │  常见问题 📥      │           │
│  └────────────────────┘ └──────────────────┘           │
└─────────────────────────────────────────────────────────┘
```

### 6.2 功能与交互

#### 6.2.1 应用头部

- **返回按钮**: 面包屑导航，点击返回市场列表
- **图标**: 应用方形封面图（若有）或首字占位图
- **名称**: h1 标题 + 信任标签 (Tag)
- **元信息**: 归属部门、责任人姓名
- **评分/点赞**: 星级评分 + 评分人数 + 点赞数
- **开始使用按钮**: 主操作按钮（蓝色），根据应用类型执行不同行为：
  - Web 应用 → 新标签页打开目标地址
  - 桌面端 → 触发下载
  - 移动端 → 展示下载链接/二维码
  - 小程序 → 展示二维码

#### 6.2.2 Tab：概述

- **简介**: 富文本/Markdown 渲染的应用详细介绍
- **截图**: Image 组件，支持缩略图点击放大预览（Modal）
- **右侧信息卡**:
  - 应用类型、分类、归属部门、维护人列表
  - 标签列表（Tag）
  - 操作手册、使用示例、常见问题下载链接（若有）

#### 6.2.3 Tab：版本

- 版本时间线列表
- 每个版本显示：版本号、发布时间、变更说明
- 当前生效版本标记为「当前版本」（Tag）
- 历史版本可展开查看详情

#### 6.2.4 Tab：评价

- **评分概览**: 总分 + 星级分布柱状图
- **评价列表**:
  - 每条评价：匿名/实名头像、星级、文字内容、时间
  - 官方回复（缩进显示，标记「官方回复」）
  - 举报按钮（`ExclamationCircleOutlined`）
- **写评价**: 按钮弹出 Modal → 星级选择 + 可选文字 + 匿名选择
- **评价筛选**: 按星级筛选（1-5星）

#### 6.2.5 Tab：风险说明

- AI 与数据风险声明清单：
  - 是否处理个人信息/敏感数据
  - 数据是否发送外部
  - 数据保留周期
  - 使用的模型/AI 提供方
  - 是否影响高风险决策
  - 用户输入限制和免责声明
- 每项风险以图标 + 文字形式展示（`CheckCircle`/`Warning`/`CloseCircle`）

#### 6.2.6 交付动作记录

- 点击「开始使用」/下载/扫码时，调用后端记录交付动作
- 不影响主操作流程（fire-and-forget）

#### 6.2.7 状态处理

| 状态 | 表现 |
|------|------|
| 加载中 | 详情页骨架屏 |
| 应用不存在 | Result 404 "应用不存在或已下架" |
| 不在受众 | Result 403 "您没有访问此应用的权限"（不暴露应用是否存在） |
| 已下架 | 页面顶部 Alert "该应用已下架" + 下架原因 |
| 已归档 | 页面顶部 Alert "该应用已归档" |

- **趋势数据** → 折线图 (ECharts Line)
- **排行数据** → 横向柱状图 (ECharts Bar horizontal)
- **流程/阶段** → 漏斗图 (ECharts Funnel)
- **部门分布** → 热力表 (ECharts Heatmap)
- 每个图表展示数据口径说明（Tooltip 或底部说明文字）
- 图表为空时展示 Empty 占位
- 每张图表提供「表格视图」切换（数据表格替代图表）
- 响应式：大屏双列，小屏单列

#### 15.2.3 时间范围选择

- 看板顶部提供时间范围选择器：近 7 天 / 近 30 天 / 近 90 天 / 自定义

#### 15.2.4 数据导出

- 具备导出权限的角色可见「导出」按钮
- 导出为 Excel/CSV
- 后台任务处理大批量导出
- 导出文件短期有效，下载链接在通知中发送

## 附录 C: 设计决策记录

| 决策 | 原因 |
|------|------|
| 管理后台风格而非门户风格 | 平台核心是管理型操作（发布、审核、治理），适合侧边栏+内容区布局 |
| 搜索框置于 Header 中间（仅市场页） | 应用市场是使用频率最高的页面，居中搜索方便触达；其他管理页面不需要全局搜索 |
| Sidebar 底部固定公告 | 平台公告需要持续可见但不干扰主操作区，底部固定是最小干扰方案 |
| 卡片网格 + 侧边栏（市场页） | 兼顾浏览效率和信息密度，侧边栏放置推荐位提升发现性 |
| 审核工作台左固定右滚动 | 审核操作按钮需要始终可见，右侧预览内容较长需要滚动 |
| 骨架屏优先于 Spin | 骨架屏提供更好的加载感知，减少布局跳动 |
| 折线图/柱状图/漏斗图/热力表 | PRD §9.4 明确指定的图表类型对应关系 |
