# innovationDetail 页面 UI 设计规格

## 目标

为“AI应用共享平台”的 `innovationDetail` 页面提供与现有应用市场、应用详情、创作者中心和登录页一致的桌面端 UI 设计。页面帮助企业员工同时完成两件事：快速理解创新需求，以及查看和补充讨论。

最终设计图：`packages/ui/src/innovationDetail.png`。

## 设计基线

- 桌面端 16:9 宽屏后台页面。
- 延续固定左侧导航和顶部全局栏。
- 主色使用 `#1677ff`，布局背景使用 `#f5f5f5`，内容背景使用白色。
- 主文字使用 `#1f1f1f`，次级文字使用 `#595959`，边框使用 `#d9d9d9`。
- 中文字体沿用 `PingFang SC`、`Microsoft YaHei` 等系统无衬线字体。
- 采用约 6px 圆角、轻边框和克制阴影；不使用卡片嵌套或指标卡片网格。

## 页面结构

### 全局框架

- 左侧导航保留“应用市场、创新广场、我的应用、通知中心、AI 助手、创作者中心”，其中“创新广场”为激活态。
- 顶部栏保留全局搜索、筛选、通知、帮助和当前用户信息。
- 内容区从面包屑“创新广场 > 需求详情”开始。

### 需求标题区

- 标题区横跨内容区域，并使用淡蓝色背景强化当前对象。
- 左侧依次显示需求名称“统一研发效能数据看板”、状态标签“进行中”“匿名展示”和需求副文。
- 右侧为操作区，采用两端对齐布局。
- “点赞 128”是标题区最右侧的主要操作；更多操作按钮位于点赞按钮左侧，点赞按钮右侧不得出现其他控件。

### 主体分栏

- 主体采用约 `60/40` 左右分栏。
- 左栏为需求说明，包含“当前问题”“期望结果”、业务价值、实施成本、风险等级、优先级、可见范围、负责人、更新时间和治理说明。
- 右栏为“补充讨论 24”，包含讨论输入区、发表按钮和讨论列表。
- 讨论列表使用行分隔，不为每条讨论创建独立卡片。

## 交互约束

- 点赞按钮位于标题区最右侧，并保持最高操作优先级。
- 讨论输入区保留表情、图片和“发表讨论”能力。
- 当前版本不实现 `@` 他人：不显示 `@` 图标、艾特提示、人员选择器或相关入口。
- 讨论列表可保留单条点赞和回复入口。
- 本次只定义加载成功状态的视觉目标；加载、错误和空状态沿用项目现有通用组件。

## 范围边界

- 本次仅交付 UI 设计图和设计规格，不修改业务代码。
- 不新增页面路由、接口、数据字段或讨论区 `@` 功能。
- 不改变现有导航、品牌、色彩、字体和全局布局体系。

## 验收标准

- 页面视觉与 `packages/ui/src` 中现有 UI 图保持一致。
- 项目名称位于标题区左侧，点赞按钮位于标题区最右侧，左右关系明确。
- 讨论输入区不存在任何 `@` 功能入口。
- 需求说明与讨论区形成清晰的 `60/40` 分栏，首屏无裁切、拥挤或卡片嵌套。
- 最终设计图保存为 `packages/ui/src/innovationDetail.png`。
